## Ideas

### Month sorting

- **Math focus:** Calendar literacy — month names in order (Jan → Dec), optionally ordinals (1st month, 2nd month, …).
- **Hook / theme:** Fix a broken calendar: some months fell out of place and need putting back.
- **Core loop:** See a calendar with empty slots; drag month labels from a pool into the correct positions.
- **Win / progress:** All slots filled in order; maybe rounds with more gaps or fewer hints.
- **Difficulty knobs:** How many months missing; show ordinals vs names only; pie layout vs linear list.
- **Open questions:** Pie-slice (year-as-circle) vs numbered list — which reads clearer for kids and stresses **order** best? Snap-to-slot feedback, wrong-slot bounce?
- **Status:** promising

### Days in a month

- **Math focus:** How many days each month has (28/29/30/31), leap year for February if we go there.
- **Hook / theme:** TBD — less thought so far.
- **Core loop:** TBD — likely pick or type day count for a given month (or match month ↔ count).
- **Win / progress:** TBD
- **Difficulty knobs:** TBD (all months vs random subset; Feb/leap as optional tier)
- **Open questions:** Separate game or second mode of month sorting? Input style (multiple choice vs typing)?
- **Status:** seed
